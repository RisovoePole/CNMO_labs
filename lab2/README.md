### Введение

В данной лабораторной работе рассматриваются итерационные методы Якоби и Гаусса - Зейделя для решения систем линейных алгебраических уравнений (СЛАУ). Эти методы позволяют приближённо находить решения в случаях, когда прямые методы нецелесообразны или дорогие по вычислениям.

Цель работы - изучить реализацию методов Якоби и Гаусса - Зейделя, сравнить их по числу итераций и времени выполнения, а также дать практические рекомендации по применимости каждого метода.

## Теоретическая часть

### Постановка задачи

Рассматривается система линейных уравнений

$$
Ax = b,
$$

где A - матрица коэффициентов, x - вектор неизвестных, b - вектор правой части.

Итерационные методы приводят систему к виду

$$
x = Bx + c.
$$

Метод Якоби предполагает, что значения вектора x на следующей итерации вычисляются полностью по значениям предыдущей итерации x^(k-1)^. Это удобно для параллельной реализации, но обычно требует большего числа итераций.

Метод Гаусса - Зейделя использует уже обновлённые компоненты вектора x внутри одной итерации (т.е. при расчёте x_i^(k)^ применяются части x_j^(k)^ для j < i), что часто приводит к более быстрой сходимости на практике.

### Выбор начального приближения

В работе в качестве начального приближения использовалось

$$
x_i^{(0)} = \frac{b_i}{a_{ii}}.
$$

Такой выбор обычно даёт приближение ближе к решению и сокращает число итераций.

### Критерий остановки

Итерационный процесс останавливается при

$$
\max_i |x_i^{(k+1)} - x_i^{(k)}| \le \varepsilon,
$$

где ε - заданная точность.

### Заключение по практической части

- Метод Гаусса - Зейделя в большинстве рассматриваемых примеров требовал меньше итераций и минутного времени исполнения по сравнению с методом Якоби. Это связано с тем, что Гаусс - Зейдель использует немедленно обновлённые компоненты решения внутри одной итерации.
- Метод Якоби хорошо подходит для параллельных реализаций, так как новые значения x^(k)^ вычисляются только по данным предыдущей итерации x^(k-1)^.
- Выбор начального приближения x~i~^(0)^ = b~i~ / a~ii~ показал себя полезным - он сокращает число итераций для обоих методов.
- Рекомендуется применять Гаусс - Зейдель всегда.
- Для стабильной сходимости полезно убедиться в диагональном преобладании матрицы A или предварительно применить перестановки/масштабирование.

## Работа с проектом

### Формат ввода

В папке `lab2/Data` находятся файлы с описанием матриц.

Формат файла (пример `example.txt`):

- Первая строка: положительное целое число - размер матрицы n (матрица должна быть квадратной, поэтому одно значение задаёт и число строк, и число столбцов).
- Далее перечислены коэффициенты для каждой строки: коэффициенты при x~1~, x~2~, ..., x~n~, после которых указан свободный член (правый значение вектора b в данной строке).
- Порядок неизвестных в каждой строке одинаков: x~1~ ... x~n~.
- Количество строк и столбцов должно соответствовать указанному размеру матрицы.
- В конце файла рекомендуется оставить одну пустую строку; пустые строки в входных данных будут игнорироваться.

**Примечание:** Хотя преобладающая диагональ матрицы A необходима для гарантированной сходиомсти обоих методов, в входных данных необязательно проверять это вручную и выставлять строки в нужном порядке т.к. в проекте уже выолняется составления преобладающей диагонали.

### Требования для запуска

Требуется установленный Elixir. Установка возможна через менеджер пакетов (nix, brew, apt, winget и др.) или скрипт установки.

Примеры команд:

```bash
# macOS
brew install elixir

# Ubuntu 
wget https://packages.erlang-solutions.com/erlang-solutions_2.0_all.deb && sudo dpkg -i erlang-solutions_2.0_all.deb && sudo apt update && sudo apt install -y esl-erlang elixir

# Windows (winget)
winget install Elixir.Elixir
```

Установить через официальный скрипт (все платформы):

```bash
curl -fsSL https://elixir-lang.org/install.sh -o install_elixir.sh
sh install_elixir.sh elixir@1.19
```

Проверить установленную версию:

```bash
elixir -v
```
